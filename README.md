# ToDo CLI Application (Лабораторная работа №2)

консольное приложение на Dart для управления списком задач (ToDo-листом). Позволяет добавлять новые задачи, просматривать их список, отмечать выполненными и удалять.

## Запуск

1. Клонировать репозиторий: `git clone https://github.com/nailvol/Dart_Lab2.git`

## Ответы на вопросы

**1. В чём разница между полем класса и обычной переменной в функции?**
Поле класса принадлежит конкретному объекту (экземпляру) и хранит его состояние на протяжении всего времени жизни этого объекта. Обычная локальная переменная объявляется внутри функции или метода, доступна только там и уничтожается сразу после завершения их работы.

**2. Что такое конструктор и зачем он нужен?**
Конструктор - это специальный метод класса (с тем же именем, что и класс), который автоматически вызывается при создании нового объекта. Он нужен для начальной инициализации полей объекта и приведения его в рабочее состояние (что особенно важно в Dart из-за механизма null-safety).

**3. Зачем нужен @override перед toString()? Что будет если его убрать?**
Аннотация @override явно указывает компилятору, что метод переопределяет одноимённый метод родительского класса (Object), защищая от случайных опечаток в названии. Если её убрать, код продолжит работать и метод всё равно переопределится, но компилятор не предупредит об ошибке, если в имени метода допущена опечатка (например, tostring()).

**4. Чем статическое поле static int _counter отличается от обычного поля? Сколько копий этого поля существует в программе?**
Обычное поле создаётся отдельно для каждого экземпляра класса (у каждой задачи свой id), а статическое поле принадлежит самому классу целиком, а не конкретным объектам. В программе существует ровно одна общая копия статического поля для всех объектов этого класса.

**5. Что означает нижнее подчёркивание в _counter?**
В Dart нижнее подчёркивание в начале имени идентификатора делает поле, метод или класс приватным (инкапсулированным). В отличие от многих других языков, в Dart приватность работает на уровне библиотеки (файла) - к _counter можно обратиться из любого места внутри файла todo.dart, но нельзя получить доступ из других файлов (например, из lab2_todo.dart).
